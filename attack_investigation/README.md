# Расследование активности на рабочей станции Windows

## Цель
По выгрузке журналов Windows и Sysmon требовалось выявить подозрительную активность, восстановить её хронологию и дерево процессов, определить затронутые учётные записи, файлы и сетевые адреса, сопоставить действия с MITRE ATT&CK. Также требовалось подготовить рекомендации по поиску такой активности на других хостах, реагированию и правилам корреляции, а результаты представить в виде HTML-отчёта и интерактивного просмотра событий.

## Просмотр результатов
1. Откройте `report.html` в современном браузере. Файл содержит выводы расследования, хронологию, дерево процессов, индикаторы, ATT&CK и рекомендации.
2. Для просмотра и фильтрации всех 70 событий откройте `viewer/index.html`. Данные встроены в HTML, поэтому отдельный файл выгрузки не требуется.
3. Запросы для поиска на других хостах находятся в `hunting_queries.md`.
4. Шаблоны правил корреляции находятся в `rules/correlation_rules.md`.
5. Восемь снимков проверки модульных тестов размещаются отдельно в каталоге `screenshots/`; пути к ним перечислены в отчёте. Снимки в архив не включены.

Оба HTML-файла открываются напрямую, без установки зависимостей и запуска локального сервера.
